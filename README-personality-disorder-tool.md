# Personality Disorder Detection Tool

A Figma Make project — an AI-generated app prototype exploring detection/assessment flows related to personality disorder traits (including narcissistic traits), built as a working React/Vite application directly from Figma.

## Design

Live Figma Make file: [View / Edit](https://www.figma.com/make/qTBfSJfUMjhvZBg1RWDaDl/Personality-Disorder-Detection-Tool)

Unlike a standard design file, this project already contains real generated source code (`App.tsx`, `package.json`, `vite.config.ts`, etc.) rather than just static screens — it's closer to a functional starting point than a visual mockup.

## Getting the code into this repo

Figma Make supports pushing directly to GitHub:
1. In the Figma Make file, open **Make settings > GitHub**
2. Authorize the GitHub connection (one-time, per team/org)
3. Select **Create Repository** (or push to this existing repo)
4. Figma Make pushes the full project structure directly

> Note: some users have reported image assets appearing corrupted after a Make-to-GitHub push (showing as unreadable/partial files). If that happens, downloading the code archive directly from Figma Make is the current workaround for getting clean image assets.

## Status

Early-stage Figma Make prototype — concept and initial code scaffold, not yet reviewed or refined for production use.

## Sensitivity note

This project deals with mental health assessment concepts. Any design or copy work should be handled thoughtfully — favoring clear, non-stigmatizing language and avoiding anything that reads as a diagnostic tool for personal use.
