# CareFind — Healthcare Practitioner Finder

A UX/UI portfolio project designed to help people find the right healthcare practitioner nearby — built around clear wireframe-to-hi-fi design work.

## Concept

CareFind lets users search for healthcare practitioners (doctors, specialists, clinics) based on location, specialty, and availability, and walks through the key stages of the design process from early wireframes to a hi-fidelity prototype.
